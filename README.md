# Base-Agent
**Base Agent** is a lightweight, extensible AI agent built with Python, featuring a web-based chat interface, local conversation memory, tool integration, optional Ollama-powered AI, web search, automation, and customizable skills. Designed for local deployment and experimentation, it provides a foundation for building and extending your own personal AI assistant.

**Key Features**
- 🤖 AI-powered chat with optional local LLM support
- 🌐 Browser-based user interface
- 🧠 Local conversation memory
- 🛠️ Extensible tools and custom skills
- 🔎 Optional web search integration
- ⚙️ Automation and scheduled tasks
- 🐳 Optional Docker deployment
- 🔒 Local-first operation with configurable network access

Built with Python, Base Agent is a starting point for developers who want to explore, customize, and build their own AI assistants.

**Getting Started:** See `README.md` for installation instructions, configuration, and usage.

**Note:** Some features require optional dependencies or additional setup.
